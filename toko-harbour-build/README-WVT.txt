Versi WVT dibuat untuk tampilan Harbour yang lebih stabil daripada Windows Terminal.

Jalankan:
- RUN-INDEK-WVT.bat  untuk Re-Index
- RUN-STOK-WVT.bat   untuk menu stok
- RUN-KASIR-WVT.bat  untuk kasir, otomatis KASSA=1

Catatan:
- Exe console lama tetap ada: indek.exe, stok.exe, cr.exe.
- Exe windowed asli: indek-wvt.exe, stok-wvt.exe, cr-wvt.exe.
- Exe windowed identitas Dua Putra Jaya: indek-dpj-wvt.exe, stok-dpj-wvt.exe.
- RUN-INDEK-WVT.bat dan RUN-STOK-WVT.bat sudah diarahkan ke versi Dua Putra Jaya.
- Program lama masih memakai koordinat 80x25, jadi WVT menjaga layar agar tidak melebar liar saat terminal diperbesar.
