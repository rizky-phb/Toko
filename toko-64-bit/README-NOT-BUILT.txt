EXE belum dibuat karena Alaska Xbase++ ProjectBuilder (pbuild.exe) tidak tersedia di mesin ini.

Untuk build:

1. Install Alaska Xbase++.
2. Pastikan pbuild.exe, xpp.exe, alink.exe, dan arc.exe ada di PATH.
3. Jalankan:

   C:\Users\User\Downloads\Toko\toko-xbase++\build\build-all.bat

Hasil build akan masuk ke folder ini.
